## 5. Foundations & Terms

### Concept Spotlight: Looped Transformer (Recurrent Depth)

You know that a standard Transformer model works by passing data through a stack of layers. More layers generally means better reasoning, but it also means more parameters and more memory. The "Looped Transformer" is a clever architectural trick that breaks this trade-off.

**What it is in plain words:** Instead of building a model with 100 different layers, you build a model with 28 layers and run the data through those same 28 layers *twice*. The model is trained specifically to handle this looping.

**Why it exists:** It gives the model the effective depth of a 56-layer model (or more) without doubling the number of parameters. This saves memory and allows for much larger effective models on the same hardware.

**A concrete worked example with real numbers:** Z.ai's GLM-5.4 has 750 billion total parameters. It has 28 layers. It runs these 28 layers twice. This gives it the effective reasoning depth of a model with 2-3 trillion parameters, but it only needs to store 750B parameters in memory. This is a massive efficiency gain.

**How it shows up in the news:** It is a way for open-weight models to compete with much larger closed-source models. It challenges the "bigger is better" assumption in AI scaling.

**A figure worth remembering:** 750B parameters, effective depth of 2-3T.

**A common misconception:** It is NOT the same as simply running the same model twice (ensemble). The model is *trained* to use the looping, so the second pass builds on the first pass's internal representations in a way that a simple double-run cannot.
